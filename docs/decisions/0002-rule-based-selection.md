# ADR 0002: 推薦は説明可能なルールベースから始める

- Status: Accepted
- Date: 2026-08-10

## Context

LLMは自然な会話と文章生成に向く一方、介入選択を自由生成に任せると、再現性、安全性、テスト容易性、説明可能性が下がる。MVP段階では学習用データも存在しない。

## Decision

候補生成、安全フィルタ、スコアリング、最終選択はアプリケーション側の決定的なロジックで行う。LLMは任意レイヤーとし、自由入力の構造化、選択済みテンプレートの表現調整、短い振り返りに限定する。

## Consequences

- 同じ入力から同じ推薦を再現しやすい。
- 推薦理由と失敗をテストできる。
- AIが利用できなくてもコアループが動く。
- 個人化の表現力は初期段階では限定される。
- 将来、十分なデータが得られた場合にPersonal Effect ModelやContextual Banditを検討できる。
