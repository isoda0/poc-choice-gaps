# ADR 0001: MVPをYouTubeのデジタル習慣へ限定する

- Status: Accepted
- Date: 2026-08-10

## Context

長期構想はスマホ、SNS、ゲーム、喫煙、飲酒など複数の対象を想定している。しかし、対象ごとに介入、安全性、規制、必要な専門性が大きく異なる。

## Decision

最初のMVPは、成人がYouTubeを無目的に開く／見続けるデジタル習慣に限定する。飲酒、薬物、重度依存など、身体的・医療的リスクが高い対象は含めない。

## Consequences

- コアループとUXの検証へ集中できる。
- 介入テンプレートと安全要件を限定できる。
- 汎用エンジンの抽象化は維持するが、未検証対象のUIは実装しない。
- 将来の対象追加には個別のTarget Packと安全レビューが必要になる。
